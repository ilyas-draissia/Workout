# Workout
a website for making a custom workout program picture through a human figure muscles with heads and all types of exercises .
# Features
1- Human figure back and front that has highlightable muscles through hover and touch which let select muscle you want to train visualy which is beginner freindly  .
2- Choose from different muscle heads .
3- Choose between exercise types (Body-weigh,Free-weight,Machine) .
4- See the exercise tutorial png or gif (isnt decided for the moment)
5- Making a program from exercises bookmarked from figure interactions or searching the exercise name for intermediate 
6- Full interface for customizing a workout plan from reps, sets and weight (imperial/metric) either with ready options for(Hypertrophy, Strength, Endurance ) all type of athletes 
7- Ability to make multiple programs up to 2 weeks splits with each day separately picked for customizable program
